# `web/` — phone runtime (no Python)

This folder is the application engine the Android APK will run.

- `engine.js` — Mothers → full shield, Via Puncti, projection, Part of Fortune, motus. Proved on 65,536 casts in Node.
- `cdn.js` — fetch `library/dataset/` through jsDelivr, cache locally.
- `engine.test.js` — `node web/engine.test.js`

Python `engine/` stays the **research and proof** copy. It is not loaded on the phone.

See `docs/APP_ARCHITECTURE.md`.
